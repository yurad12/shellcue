# 다음에 할 일

먼저 매일 쓰면서 걸리는 부분을 다듬고, 그다음 원하는 세션까지 가는 조작을 줄인다. 한 번에 한 묶음씩 진행한다.

## 먼저: 패널과 메모 편집

인라인 편집을 유지하면서 Esc·외부 클릭으로 닫기, 이동 성공 후 닫기, 두 줄 메모 미리보기를 구현했다. 초안은 앱 상태에 두어 패널을 닫아도 유지한다. 저장하거나 취소하면 편집을 마친다. 앱을 종료하면 미저장 초안은 사라진다.

초안 유지·저장·취소·저장 실패·이동 실패 테스트를 더해 전체 25개가 통과했다. 앱 실행도 확인했지만 화면 제어 연결이 시간 초과되어 아래 동작은 직접 확인이 남아 있다.

- 이름과 메모에서 이모지 선택창을 클릭해도 패널이 닫히지 않고 입력되는지
- Enter·Shift-Enter 줄바꿈과 저장 후 두 줄 미리보기가 맞는지
- Esc·외부 클릭·아이콘 재클릭으로 닫았다 열어도 편집 내용이 그대로 남는지
- 취소는 초안만 버리고, 터미널 이동은 성공했을 때만 패널을 닫는지

이 확인을 마친 뒤 키보드 이동 작업으로 넘어간다.

## 이어서: 키보드로 세션 이동

단축키로 패널을 열고, 검색한 뒤 방향키와 Enter로 이동할 수 있게 한다. 패널을 열면 검색창에 바로 입력할 수 있어야 한다.

8~12개 세션을 열어두고 마우스 없이 원하는 곳으로 이동해 본다. 갱신 도중에도 선택한 대상이 바뀌지 않아야 한다.

## 그다음: 구분하기 쉬운 목록과 빠른 응답

- 같은 프로젝트의 세션을 이름, 짧은 경로, 실행 명령으로 구분하기 쉽게 만든다. 브랜치나 worktree는 실제 구분에 도움이 될 때 추가한다.
- 이름이나 상태가 바뀌어도 행이 불필요하게 움직이지 않게 한다.
- 세션 검색과 프로세스 조회가 화면 처리를 막는지 확인한다. 세션이 많아도 검색·메모 입력이 끊기지 않게 개선한다.

## 실제 터미널에서 확인할 것

자동 테스트와 별개로 남아 있는 확인 항목이다.

- Terminal과 iTerm2를 함께 열었을 때 프로젝트 그룹과 상태가 맞는지
- 탭을 옮기거나 앱을 다시 실행해도 이름과 메모가 같은 세션에 붙는지
- 닫힌 세션이나 재사용된 TTY에 예전 메모가 잘못 붙지 않는지
- 한쪽 터미널의 권한이 없어도 다른 쪽 목록과 이동은 작동하는지

구형 Terminal 메모는 파일에 보존되어 있지만 세션 수명을 확인할 정보가 없어 자동으로 옮기지 않는다. iTerm 메모는 기존 세션 ID를 그대로 쓴다.

## 다른 사람에게 배포하기 전

버전을 빌드마다 구분하고, ZIP을 받은 사람이 설치부터 권한 허용·첫 세션 이동까지 진행해 본다. 개발 환경이 없는 별도 Mac에서도 확인한다. Developer ID 서명과 Apple 공증도 준비한다.

최근 닫힌 세션, AI 도구별 상태, 추가 터미널 지원은 위 작업을 마친 뒤 필요를 보고 결정한다.
