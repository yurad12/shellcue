# ADR-0001: 터미널 독립 구조

상태: 채택  
날짜: 2026-09-22

## 배경

ShellCue는 macOS Terminal과 iTerm2를 첫 대상으로 지원한다. 명령 상태는 zsh가 가장 정확히 알고 있지만, 창·탭·pane을 찾고 활성화하는 방법은 터미널 앱마다 다르다.

## 결정

명령 상태 수집과 터미널 제어를 분리한다.

- 공통 zsh 연동이 셸 시작, 명령 시작·종료, 경로 변경을 전달한다.
- 터미널별 어댑터가 열린 세션 발견과 포커스 이동을 담당한다.
- TTY, 셸 인스턴스 UUID, PID, 앱 세션 ID를 조합해 두 정보를 연결한다.

## 결과

- 다른 터미널은 새 어댑터를 추가해 지원할 수 있다.
- 터미널 어댑터가 실패해도 zsh에서 받은 작업 상태와 메모는 보존할 수 있다.
- TTY 재사용과 앱 재시작 시 잘못 연결되는 위험이 있어 재연결 로직을 별도로 검증해야 한다.
